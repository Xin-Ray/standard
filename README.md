# Standards Library

由 **[Xin-Ray](https://github.com/Xin-Ray)** 创建的可复用规范库，涵盖 [Research Papers](standards/papers/README.md)、[Slides](standards/slides/README.md)（[Design Tokens](standards/slides/design-tokens.json) · [Slide Patterns](standards/slides/slide-patterns.json) · [Claude Guide](standards/slides/CLAUDE.md)）及未来更多主题。**更新规则**：每个类别最多 **50 条有效标准**，相似规则优先合并；每条必须标注 **编号、层级、优先级 P0/P1/P2、可操作的检验方式、适用项目、来源、贡献者和备注**，区分原始提出者与整理者。详情见 [CONTRIBUTING.md](CONTRIBUTING.md)。
