# slides

## 做好 Slides 的 7 条核心规则

### 1. 先结论，后解释（Conclusion First）

开场就告诉观众：研究什么、发现什么、为什么重要。

### 2. 总—分—总（Structure）

开头给核心观点 → 中间展示证据 → 结尾强化结论。

### 3. 一页一个观点（One Slide, One Message）

每页只回答一个问题，不要同时讲多个主题。

### 4. 标题就是结论（Assertion Titles）

- ❌ Model Performance
- ✅ Our Model Outperforms Four Baselines

### 5. 图表优先，文字辅助（Show, Don't Tell）

尽量用图表、流程图和模型架构代替大段文字。突出关键数字。

### 6. 讲故事，而不是堆信息（Storytelling）

按照 **Problem → Challenge → Solution → Evidence → Impact** 展开，让观众理解每一步为什么存在。

### 7. 少即是多（Less Is More）

删除所有不支持核心观点的信息。每页最好能在 30–60 秒内讲清楚。

## 学术研究 Slides 推荐结构（8–10 页）

| 页面 | 核心问题 |
| --- | --- |
| 1. Takeaway | 最重要的发现是什么？ |
| 2. Background | 为什么这个问题值得研究？ |
| 3. Research Gap | 现有方法有什么不足？ |
| 4. Proposed Method | 我们如何解决？ |
| 5. Model Design | 模型为什么这样设计？ |
| 6. Experimental Setup | 如何公平验证？ |
| 7. Main Results | 结果是否支持我们的观点？ |
| 8. Analysis | 为什么有效？哪些条件下有效？ |
| 9. Limitations | 有哪些限制？ |
| 10. Conclusion | 观众应该记住什么？ |

## 最重要的一条

> **Slides 不是论文的缩写，而是帮助观众理解并相信你核心观点的视觉叙事。**

## 判断标准

观众只看每页**标题**和**关键图表**，就能理解整个研究故事。
